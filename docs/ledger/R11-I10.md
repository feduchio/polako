# R11 I10 — a mutant script, and no unmeasured cut

**Date:** 2026-09-25.

`scripts/mutate-touched.mjs` copies the tree to `/tmp`, flips each simple `if (` added since a ref to `if (false)` and `if (true)`, and runs the matching test. The host checkout is not touched.

A trial on `HEAD~1..HEAD` (the MCP commit), limited to two conditions:

| | Flip | Result |
|---|---|---|
| M0 | `if (false)` in `src/mcp/index.ts` | SURVIVE |
| M0 | `if (true)` | KILL |
| M1 | both flips | KILL |

One flip survived. That is why `service.budget-override.test.ts` and the P1.1 block in `review-cost.test.ts` were not collapsed in this commit. The council's condition was that a module is thinned only after a sweep of it still kills the same mutants. This trial did not finish that sweep, and it already found a condition the suite does not need. Cutting those files by eye would repeat the failure the sweep is there to catch.

Next use: `node scripts/mutate-touched.mjs <ref> --limit N` on the budget and review modules, then delete a case only when every flip that was killed before the deletion is still killed.

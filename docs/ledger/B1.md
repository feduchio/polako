# B1 — AgentRunner

**Status:** ACCEPTED  
**Class default:** PHASE_REQUIRED

**Prompt:** real tool loop, actual source modification, finish requires fresh evidence.

## Required behavior

1. `AgentRunner` executes one task in one fresh context pack. No transcript inheritance across tasks or candidates.
2. Tool loop: `read`, `list`, `search`, `repo_intel`, `write`, `apply_patch`, `run_command`, `request_context`, `finish`.
3. Tools operate only inside the candidate `SandboxHandle`. Writes/patches outside the worktree fail closed.
4. `run_command` uses the existing Phase A command policy (exact checks, named package scripts, optional trailing-argv allowlist, no generic wildcards).
5. Repository fragments returned by tools are untrusted DATA/EVIDENCE (A11 boundary). The runner must not elevate them to instructions.
6. Turn and token budgets are enforced. Exhaustion is a failed worker outcome, not a silent `finish`.
7. Transcript of messages/tool calls/results is persisted to CAS and referenced from the candidate.
8. `finish` is accepted only with **fresh evidence produced in this worker execution** (new file hashes, command results, or patch application records from this loop). A `finish` with empty evidence, reused sibling-candidate evidence, or no source mutation when the task `touchesProductCode=true` is rejected.
9. Model names are not hardcoded in the runner; the broker supplies the completion function / model ref.
10. Implements `CandidateWorker` from Phase A `src/engine/candidates.ts` so B2 can call it without a parallel worker interface.

## Prohibited shortcuts

- Scripted/canned tool traces as the production runner.
- Shared mutable runner instance across candidates (factory must create fresh runners).
- `finish` that always succeeds.
- Bypassing sandbox command policy via `bypassPolicy` in production.
- Porting donor `src/agents/*` without re-checking this contract.

## Deterministic evidence

- Unit tests with `ScriptedProvider`: read/write/patch/search/run_command/finish happy path.
- Finish without evidence → rejected.
- Finish with `touchesProductCode` and no worktree diff vs base → rejected.
- Path escape write/patch → rejected.
- Disallowed command → rejected; allowlisted check command → executed in sandbox.
- Fresh factory: mutating runner state cannot leak to a sibling candidate.
- Transcript CAS artifact exists and is non-empty after a completed loop.
- `pnpm check` on the B1 artifact.

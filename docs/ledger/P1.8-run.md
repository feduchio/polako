## Resulting production rules

- `pending_integration` is a recognised state, not legacy. Every pending entry
  is skipped until its fixing task integrates; missing or unknown state still
  fails closed.
- After one task integrates, unstarted `PENDING`/`READY` siblings are rebased
  to the accepted checkpoint. Otherwise the newly cumulative regression would
  run against code that predates the fix it protects.
- Only runner-plausible source tests are eligible. Strong `.test`/`.spec`
  names outrank direct test-root fallbacks; fixture, helper, mock, snapshot and
  data paths do not become the protected artifact by sorting first.
- Git blob bytes are stored exactly. Invalid UTF-8 is not replacement-decoded,
  trailing newlines are not trimmed, and capped output fails rather than
  hashing a prefix.
- Once the run head advances, every admission outcome has an FSM exit. The task
  is recorded `INTEGRATED`; a capture failure terminates the run explicitly as
  `FAILED` instead of leaving `INTEGRATING` unrecoverable.

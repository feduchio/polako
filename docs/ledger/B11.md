## Implementation notes

- **Named adapters:** `OpenRouterProvider`, `GeminiProvider`, and `GroqProvider` in `src/providers/{openrouter,gemini,groq}.ts`. Each wraps `OpenAICompatProvider` with provider-specific base URLs and kinds; OpenRouter adds attribution headers (`HTTP-Referer`, `X-Title`).
- **Config wiring:** `createProviderFromConfig` (`src/providers/factory.ts`) is used by `loadConfiguredProviders` in `src/daemon/composition.ts`. Providers load only when `config.providers[].enabled`, `apiKeyEnv` is set, and `SecretStore.fromFile(~/.polish/secrets.env)` has the named env var.
- **Capability probes:** `probeModelCapabilities` (`src/broker/capabilityProbe.ts`) runs health → tools → json smoke calls. Results are stored in the catalog with `source: "probe"`; per-model availability is tracked separately from provider availability. Probe throws disable the model; provider `listModels` failures mark the provider unavailable without crashing discovery.
- **Production composition:** `createDiscoveringModelsDriverFromCatalog` calls `catalog.discover({ capabilityProbe })`, emits `model.probed` events (checks + capabilities, no secrets), then `models.discovered`.
- **Tests:** recorded HTTP fixtures under `fixtures/providers/`; no live network in `pnpm check`.

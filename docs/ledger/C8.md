## MISSION_CRITICAL invariants

1. **Strategy / persistence separation.** `AuditionStrategy` scores a model on a fixed task set and must not touch Store/DB/events. Persistence goes **only** through `ModelObservationRepository.recordAudition` onto `GLOBAL_MODEL_OBSERVATIONS_RUN_ID`. No direct table writes, no mission-run-id audition events, no companion `recordQuality` for the same audition scores.
2. **Optional matrix (all zero-call).** Each of the following yields zero provider calls and an unchanged observation list: missing `[audition]` section; `audition.enabled=false` (even if `strategy=micro-tasks`); `audition.enabled=true` + `strategy=noop`; `defaultConfig`. Production constructs `NoopAuditionStrategy` on those paths. Only `enabled=true` + `strategy=micro-tasks` may call providers.
3. **Global vs per-run.** Audition scores are global. `ModelBroker.restore(runId)` must leave (a) the observation list byte-identical for historical rows and (b) catalog quality equal to the same ordered quality+audition EMA as before restore / a fresh `restoreCatalog`. C8 must not regress A12.9.
4. **Honest scores at the persist boundary.** `recordAudition` rejects non-finite scores **before** append (no silent `Infinity→1.0`, no `NaN` reaching the log). Finite scores clamp to `[0,1]`. Default exact-match scorer: match → `1`, mismatch → `0`, missing `expected` → `0` (or skip persist — pick skip-or-zero consistently and test it). Rejected scores must not invent `1.0`.
5. **Deterministic catalog replay.** `observedAt` values within one audition pass must be strictly increasing (or otherwise tie-break by event `seq`) so EMA fold order is deterministic. After `restoreCatalog` / rebuild, catalog quality for cataloged models equals the exact existing EMA fold of quality + eligible audition scores. Duplicate replay of the same observation prefix is idempotent under that fold.
6. **Routing impact guard.** Until a model has at least `audition.minScoresForRouting` (default **3**) persisted audition observations, `restoreCatalog` must **not** feed that model’s audition scores into `stats.quality` (observations still persist). Once the threshold is met, fold all of that model’s audition scores in deterministic order. A single false zero must not permanently demote a model below routing usefulness without that sample floor.
7. **Cost, budget, broker.** Production micro-task completions go through `ModelBroker.complete` with a real run id (the discovering run) so budget/quota apply. Models are filtered with `isCostEligible` / `costEligibilityFromConfig(config.routing)` before audition. Bound: at most `audition.maxModels` × `audition.maxTasks` (small defaults). Excess → skip fail-closed. Acceptance uses `ScriptedProvider` only — no live/paid APIs. Raw `ProviderAdapter` only as injected scripted transport in unit tests.
8. **No C3/C4 scorers.** Default and production scorers must not import or call C3 sidecar, `VerifierAdapter`, `PairwiseJudge`, or C4 debate. Production `micro-tasks` uses exact-match (or an injected pure function) only.
9. **No self-oracle / no DONE authority.** Audition must not accept C8 itself and must not replace gates or declare run `DONE`.
10. **Bounded micro-tasks.** Default non-noop strategy uses a small explicit task list (ids + prompts + optional expected). No shell, no product-code edits, no user-checkout mutation.
11. **Production wiring (named).** C8 is unmet unless `installProductionDrivers` / `createDiscoveringModelsDriverFromCatalog` (or the single composition function that owns DISCOVERING_MODELS) constructs the configured strategy and, when `enabled=true` + `micro-tasks`, calls `ModelAuditioner.run` through `recordAudition` after catalog discovery and before the phase completes. Missing config / disabled / noop → `NoopAuditionStrategy` and zero `model-audition:` provider calls on that path.
12. **Re-audition idempotence.** For each `(modelRefKey, taskId)` with a non-stale persisted audition observation (same process discovery pass, or within configured TTL defaulting to “skip if any prior audition for that pair exists”), do not re-call the provider. A second DISCOVERING_MODELS entry on the same Store prefix with existing pairs makes zero new audition provider calls.
13. **Provenance.** Each persisted audition observation records `model`, `taskId`, `score`, `observedAt`, optional `detail`. Strategy name and `audition.enabled` must appear in `detail` or a dedicated field/event that survives projection (extend schema with back-compat if needed — do not rely on stripped extra JSON fields).

## Deterministic acceptance checks

1. Full optional matrix (invariant 2): all four paths zero-call / observation list unchanged.
2. Scripted micro-task: match → 1, mismatch → 0, missing expected → 0 (or skip); persisted `kind:"audition"` with stable `taskId`; purpose metadata `model-audition:<taskId>`.
3. After `ModelAuditioner.run`, fresh `restoreCatalog` yields **exact** EMA equality for a model with ≥2 differing scores and ≥ `minScoresForRouting` samples.
4. Below `minScoresForRouting`, audition rows persist but catalog `stats.quality` is not driven by those audition scores alone.
5. `ModelBroker.restore(otherRunId)` preserves observation list and catalog quality EMA (A12.9).
6. Non-finite score rejected before append; no `Infinity→1.0` invent.
7. Strategies constructed without Store/Db/EventLog dependencies; only auditioner calls `recordAudition`.
8. Production DISCOVERING_MODELS path: disabled/noop → zero `model-audition:` calls; enabled micro-tasks → auditioner invoked; second pass with existing pairs → zero new audition calls.
9. Under default `free_only`, a paid-only cataloged model is not auditioned.
10. With C3/C4 modules present in-tree, a micro-task run does not invoke sidecar/VerifierAdapter/PairwiseJudge/debate.
11. Named regression files stay green: `src/broker/observations.a12.test.ts`, `src/broker/observations.event-sourced.integrity.test.ts`, plus C2/C3/C4/broker/control-plane suites.

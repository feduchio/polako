# A6 — Sandbox: env scrubbing, process runner, command allowlist, git wrapper, WorktreeSandbox, output compressor

## Contract

Scope: `src/sandbox/**`. May import `domain/`, `shared/`. Threat model: `docs/THREAT_MODEL.md` (trusted project,
worktree = workspace isolation only, env scrubbing = defense in depth).

1. `pnpm check` passes.
2. `scrubEnv`: output contains only allowlisted names from the source (minus any matching a deny pattern),
   fixed deterministic vars (`CI=1`, `NO_COLOR=1`, ...), and `extra` (minus deny matches). Nothing else leaks.
3. `runProcess`: no shell ever (`shell: false`); child in its own process group; on timeout or abort the whole
   group receives SIGTERM then SIGKILL; stdout/stderr capped at `maxOutputBytes` with `truncated` flag;
   spawn failure rejects with `SANDBOX_ERROR`; result records `timedOut`/`aborted`/exit code/signal/duration.
4. `CommandPolicy.check`: allows exact argv-prefix matches of the rules (read-only git, search tools, project
   check commands, `<pm> run|test|exec|ls|why`); never allows `sh|bash|zsh -c` or bare shell operators
   (`|`, `&&`, `;`, `>`, `>>`, `<`) even when `allowArbitrary` is true.
5. `Git`: argv-only, fixed identity, `GIT_TERMINAL_PROMPT=0`; `commitAll` returns null when nothing changed;
   `cherryPick` reports conflicts and leaves the worktree clean on failure; `fastForward` refuses non-ancestors.
6. `WorktreeSandbox.create`: worktree under `<root>/<id>` from `baseCommit`, on a new branch or detached;
   refuses existing path/branch; `run` enforces the policy (unless `bypassPolicy`) and the scrubbed env;
   `destroy` removes the worktree and directory (branch is kept); `list` returns only this root's worktrees
   (realpath-normalized); `isolates === false`.
7. `compressOutput`: error-like lines surfaced first, head/tail preserved, noise filtered, `renderCompressed`
   respects `maxChars`.

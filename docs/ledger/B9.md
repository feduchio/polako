# B9 — Daemon, CLI, MCP (one production composition)

**Status:** CONTRACT LOCKED  
**Class default:** PHASE_REQUIRED  
**Plan:** Fable §17 B9; ADR-0001 daemon-centric; apply semantics.  
**Prompt:** one production composition; no duplicate orchestration; pause/resume/stop.

## Required behavior

1. `polishd` owns state and execution. CLI and MCP are thin JSON-RPC facades over the unix socket (dependency-cruiser rule already forbids cli/mcp → engine).
2. **Single production composition** installs real phase drivers for every Phase B phase (discovery, baseline, interpret, models, plan, execute, gate, compare, integrate, review, validate, convergence, runtime). `RunEngine` default stubs remain available for A5 tests only; daemon construction must not use stub drivers for those phases.
3. Autostart: CLI starts `polishd` if the socket is absent; closing Cursor does not stop the daemon.
4. CLI commands (PHASE_REQUIRED): `project add`, `run` (mission, runtime mode, budget flags), `status`, `log [--follow]`, `diff`, `pause`, `resume`, `stop`, `kill`, `answer` (NEEDS_HUMAN), `apply`.
5. `apply` fast-forwards the user's original clean branch; refuses dirty user tree / non-ff. DONE does not apply automatically.
6. MCP exposes the same operations; no second orchestrator.
7. Cursor skill `.cursor/skills/polish/SKILL.md` is tracked in git (gitignore exception). Doctor/gc remain original-plan C9 and are not required here.
8. Pause/resume/stop/kill use the existing A5 control plane. Crash recovery: daemon restart + `engine.recover()` continues from projections.

## Prohibited shortcuts

- Production path constructing `RunEngine` with stub drivers.
- Tests calling `new RunEngine` with substituted phase drivers and calling that "production E2E" (B10 forbids this as acceptance).
- Duplicate phase logic in CLI.
- Hidden merge on DONE.

## Deterministic evidence

- Composition unit test: daemon engine drivers for DISCOVERING_PROJECT…CONVERGENCE_CHECK are not `stubDriverFor`.
- CLI parse tests for required commands.
- Apply: ff succeeds on clean branch; dirty/non-ff rejected; user files unchanged on DONE without apply.
- RPC pause/resume/stop round-trip against an in-process daemon with fake clock/scripted provider.
- Skill file is tracked (`git ls-files .cursor/skills/polish/SKILL.md`).
- `pnpm check`.

## Global invariants

Daemon-centric; two-axis FSM; safe dirty-repo semantics; apply explicit.

# A12 — Phase A integrated invariant audit and foundational fixes

## Contract

Scope: defects and missing cross-module invariants in the already accepted A1–A11
foundation only. AgentRunner, live candidate execution/integration, convergence, runtime
execution, and real providers remain Phase B/C work.

Deterministic gate: `pnpm check`, plus the focused adversarial and integration tests below.

1. Independent gates compare candidate evidence to `BaselineSnapshot`; unchanged baseline
   failures do not fail a candidate, while newly failing tests, degraded checks, missing
   checks/tests, and diagnostic fingerprint changes remain representable as regressions.
2. Candidate protected-path modifications are inspected and rejected before canonical
   artifacts are materialized into a separate evaluation checkout. A regression test
   commits a modified protected artifact and observes `FAILED_GATES` semantics.
3. Mission Acceptance Corpus is a first-class, cumulative mission/run acceptance
   abstraction persisted through events/projections. It accepts generalized evidence kinds
   without implementing runtime scenarios in A12.
4. `ProtectedChangeWaiver` is deny-by-default, scoped to an explicit task/mission
   requirement, independently validated, causally linked, and cannot be self-issued by a
   worker. Only matching protected changes are waived.
5. Command policy uses explicit capabilities: exact discovered commands, exact package
   scripts, read-only git operations with safe option handling, dedicated safe search/list
   commands, and explicit task grants. Broad `pnpm run *`, `pnpm exec *`, `find *`, and
   arbitrary option-bearing search prefixes are not security boundaries.
6. BasicIntel passes LLM-controlled patterns as explicit pattern operands separated from
   options; leading-dash/adversarial queries cannot become `rg` options.
7. Fact promotion verifies that the evidence event exists, belongs to the same run, has an
   allowed deterministic/validated evidence type, and is recorded as explicit provenance.
8. Fact consolidation chooses the strongest semantic duplicate (`verified` above
   deterministic/user-stated above llm-inferred), then recency/id deterministically, and
   preserves stronger provenance/evidence references.
9. Restoring one run's usage state does not reset global historical model observations.
   Full model audition remains C8.
10. CodeGraph doctor/contract probe discovers the real binary's version, help/capabilities,
    supported command/options, and a minimal fixture query; compatibility is versioned or
    capability-driven. Fake CLI tests remain deterministic but do not claim real
    compatibility.
11. Every canonical persisted event carries a schema/version discriminator. Existing
    database histories migrate/read safely; JSONL remains a rebuildable mirror.
12. Worker context budgeting never drops mission intent, task contract, critical base
    policy, or instruction hierarchy. Optional domain/task protocol material and repository
    context remain droppable.
13. Repository fragments/retrieval are explicitly delimited and labelled untrusted
    data/evidence below system/runtime, mission, protocol, and task instructions. A fixture
    containing `Ignore previous instructions...` remains quoted repository content.
14. Dirty target repositories are never stashed, reset, or committed implicitly. A clean
    tree is required by default; any future `--include-dirty` path must be explicit and use
    an isolated synthetic snapshot/ref.
15. Contradictory baseline results trigger bounded confirmation and persist flakiness
    evidence rather than silently becoming deterministic regressions.
16. CheckRunner can persist complete stdout/stderr/diagnostics as forensic CAS artifacts
    while retaining a separate compact structured summary.

  snapshot implementation remains B/CLI work.

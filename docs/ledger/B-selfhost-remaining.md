18. Worker tool-loop replays the whole transcript, so cumulative token cost is quadratic in turns and pre-empts the contracted `agent.maxTurns` bound. `AgentRunner.runLoop` sends `messages: [...messages]` on every call (`src/agents/runner.ts:71`) after appending the assistant message (`:89`) and every tool result (`:122`), charges the entire prompt against one cumulative counter (`totalTokens += inputTokens + outputTokens`, `:90`), and passes the remainder as that call's output cap (`remainingTokens`, `:66`). Turn capacity therefore grows as the square root of the token budget, not linearly, and the per-call generation allowance shrinks monotonically as the transcript grows. Two consequences at production defaults (`agent.maxTurns` 32, `src/domain/config.ts:92`; `maxTaskTokens` null → `32_000`, `src/daemon/composition.ts:455`): the token budget binds well before the contracted turn count, so the `agent.maxTurns` knob accepted in `docs/ledger/B-bootstrap-discovery.md` is not the effective bound; and exhaustion returns `BUDGET_EXCEEDED` → `status: "failed"` (`src/agents/runner.ts:277-282`), so candidates can drop out of `COMPARING` by transcript length rather than by evidence, biasing the tournament frontier. `read` output is the dominant growth term and is never evicted, so re-reading one file duplicates it in context for the remainder of the loop. Illustrative arithmetic only (~8 of 32 turns at a 1.1k base prompt and ~800-token tool results) — a real figure must be computed from stored `agent_transcript` artifacts before any contract is frozen. Reference architecture: SKILL.state (arXiv 2608.26263), bounded `(P, Σ_t, O_t)` prompt with the reasoning trace discarded after a runtime-validated state patch. That paper's stated auditing limitation does not apply here: `persistResult` already archives the full transcript to CAS (`src/agents/runner.ts:246-251`), so Polish can drop history from the context window while keeping it in the event log. Found while evaluating arXiv 2608.26263 against the tree. **Scheduled 2026-09-10** into the pause block after finding 19 and before items 11–15; contract not yet drafted. Ordering rationale and the measurement prerequisite are in *Prompt-path ordering constraints*, `docs/ledger/PHASE-C.md`.

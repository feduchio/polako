1. deps-ts reaches `DONE` and the worktree test can run.

3. the hfb2 search replay ends `FAILED` / `no_candidate_finished` with a `STALLED` candidate.
4. the jc02 listing replay never shows `node_modules/` to the model.
5. an account-scoped 429 ends the run (`FAILED` or `NEEDS_HUMAN`) with a reason, and the reason is not `repeated_failure`.
6. a finding whose `evidence` is an object still lands in `findings`.
7. one progress family is recorded `off` (`insufficient_families: 1`) before any `worker.started`.

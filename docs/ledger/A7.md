# A7 — Project: registry, discovery, CheckRunner, BaselineSnapshot, SilencingDetector, IndependentGates

## Contract

Scope: `src/project/**`. May import `domain/`, `shared/`, `sandbox/`.

1. `pnpm check` passes.
2. `ProjectRegistry` registers project roots by path and optional alias; `discoverProject` reads `package.json`
   and known manifest files, detects package manager (lockfile order: pnpm, yarn, bun, npm), infers test framework
   hint (vitest/jest/unknown), and produces mandatory checks from scripts (`test`, `lint`, `typecheck`, `build`).
3. `ProfileCache` returns a cached profile until any tracked manifest hash or `scriptsHash` changes.
4. `runChecks` executes profile checks inside a `SandboxHandle`, maps process outcome to `CheckStatus`, and parses
   test summaries for vitest/jest (best-effort; omitted summary is not invented).
5. `buildBaselineSnapshot` captures check results + manifest hashes + scripts hash at a commit (pre-change).
6. `detectSilencing` flags: scripts hash change, config hash change vs baseline, `.only`/`.skip` in diff,
   `@ts-ignore` / `eslint-disable` in diff, removed test files in diff.
7. `runIndependentGates`: materialize acceptance artifacts into a clean checkout, verify protected paths,
   run checks, run silencing detection; `passed` only when mandatory checks pass, no acceptance problems,
   and no silencing findings.

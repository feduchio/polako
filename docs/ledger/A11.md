# A11 — Context builders: mission/supervisor/worker packs, facts provenance, progressive disclosure

## Contract

Scope: `src/context/**`. May import `domain/`, `shared/`, `store/`, `protocols/`, `project/`,
`intel/` (types/results only as inputs — builders do not construct intel backends).

1. `pnpm check` passes.
2. `buildMissionContext(mission)` returns the full immutable mission payload (text, constraints,
   decisions, hash) for always-on inclusion; it does not mutate the mission.
3. `buildSupervisorView(input)` includes a compressed task graph summary, top-K current facts
   ranked by tag/file overlap, recent decisions (decision facts), latest checkpoints with
   evidence digests, and unresolved findings (`VALID`/`VALIDATING`/`UNCERTAIN`).
4. `buildWorkerContextPack(input)` includes task identity/acceptance, protocol `promptText` +
   hash, relevant file *fragments* (not whole files by default), profile architecture notes,
   invariants (ground-truth facts), validated findings touching task files, failed attempts
   with progressive disclosure by attempt number, and available tool names; `fitWorkerPack`
   enforces `contextBudget.maxPackTokens` by dropping lowest-priority sections (never mission
   or task/acceptance).
5. Facts in any prompt text are labelled by provenance; `llm_inferred` are explicitly marked
   as hypotheses (`formatFactForPrompt`). `isGroundTruth` facts are unmarked hypotheses.
6. `FactsService` appends `fact.recorded` / `fact.promoted` / `fact.superseded` via the store.
   `promote(factId, evidenceEventId)` succeeds only when the current projection is
   `llm_inferred` (A2 carry-over: confidence never promotes). `consolidate` dedupes equal
   statements (normalized) among current facts and supersedes losers.
7. Progressive disclosure: attempt `1` → summaries only; `2` → + error excerpts; `≥3` → full
   attempt records provided in the input.

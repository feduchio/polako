# A3 — Store: node:sqlite, migrations, event log, projections, artifact CAS, acceptance storage

## Contract

Scope: `src/store/**`. May import only `domain/` and `shared/` (dependency-cruiser enforced).

1. `pnpm check` passes.
2. `openDb` applies versioned migrations exactly once (`schema_version`), refuses gaps, WAL on file dbs.
3. `EventLog.append` is atomic: events + projections in one transaction; `seq` is per-run monotonic starting at 0;
   an invalid snapshot anywhere in the batch rolls back the whole batch (no events, no projections).
4. Projections are driven only by `PROJECTION_RULES` (event type + payload field → table); repositories are read-only.
   `rebuildProjections(runId)` after arbitrary corruption of projection rows yields state identical to live state.
5. Unknown event types are stored and replayed without error.
6. `causalChain` walks `causedBy` backwards (bounded); `effects` walks forwards via `event_causes`.
7. JSONL mirror at `runs/<runId>/events.jsonl` is derived-only (never read back).
8. `ArtifactStore` is content-addressed (sha256), idempotent, verifies hash on read, rejects malformed hashes (no path traversal).
9. `AcceptanceStorage.verify` reports `missing`/`modified` protected paths against stored hashes; `materialize`
   overwrites them from the CAS; both refuse `relativePath` escaping the checkout root.
10. Nested `transaction()` calls join the outer transaction (`db.isTransaction`) and roll back together.

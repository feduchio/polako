# A8 — Broker core: provider adapters, catalog, router, quota/budget, secrets, scripted + record/replay

## Contract

Scope: `src/broker/**`, `src/providers/**`. Broker may import `domain/`, `shared/`, `store/`; providers import `broker/types` + `shared/`.

1. `pnpm check` passes.
2. `ProviderAdapter` is a dumb transport (no retries, budgets, logging). `ProviderError.kind` classifies failures;
   `retryable` is true only for `rate_limit | server | timeout | network`.
3. `ModelBroker.complete` is the single entry point: budget check *before* the call (`BudgetTracker.assertWithin`),
   quota slot per provider (`QuotaTracker`: concurrency, RPM window, cool-downs from `retry-after`), retries with
   exponential backoff only for retryable errors up to `RetryPolicy.maxAttempts`, auth failure marks the provider
   unavailable, abort propagates immediately.
4. Every attempt sequence yields exactly one `model.call` event (ok or failed) with request and (if any) response
   stored as CAS artifacts after `SecretStore.redact`. Event `runId` = request `metadata.runId`; `causedBy` from
   metadata. `ModelBroker.restore(runId)` rebuilds budget usage and catalog stats from those events.
5. `ModelCatalog`: union of provider-advertised and config-declared models keyed by `provider/model`; per-model
   stats (calls, failures, latency EMA, quality EMA fed by the engine). No model names in code.
6. `ModelRouter.rank/select`: eligibility filters (tier, tools, json, context, exclude, availability); score =
   expected quality (observed or tier prior) − failure penalty − cost penalty + diversity bonus; the diversity
   bonus applies only above `minQualityForRotation`, and greedy family spread drops the bonus for already-chosen
   families. Pinned models come first if eligible. Deterministic tie-break by model key.
7. `SecretStore`: loads `secrets.env` (+ `*_API_KEY|*_TOKEN` from process env as fallback), warns on mode ≠ 600,
   `names()` never exposes values, `redact()` replaces every value ≥ 8 chars.
8. `ScriptedProvider`: deterministic scripted steps per model (reply/error/fn), echo fallback, records calls.
9. `RecordReplayProvider`: cassette keyed by hash of (model, messages, tools, responseFormat, maxTokens, temperature)
   — metadata and signal excluded; replay never touches the inner adapter and fails loudly on a miss.
10. `OpenAICompatProvider` (OpenRouter/Groq): maps messages/tools/response_format/max_tokens, tool calls back,
    usage incl. cost when provided; classifies 401/403→auth, 404→not_found, 429→rate_limit (+retry-after),
    408/504→timeout, 5xx→server, else bad_request/context_length; own timeout → `timeout`; caller abort propagates.
    Family from `vendor/` prefix or name stems; tier from price then context (heuristic prior only).

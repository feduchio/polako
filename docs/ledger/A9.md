# A9 — Protocol Registry: SKILL.md loader, composer, budget, bundle hash

## Contract

Scope: `src/protocols/**` and repo-root `protocols/**`. May import `domain/`, `shared/` only
(dependency-cruiser enforced). Protocol markdown bodies are data, not executable code.

1. `pnpm check` passes.
2. `ProtocolRegistry.load(rootDir)` discovers `*/SKILL.md` under the protocols root, parses
   agentskills.io YAML frontmatter (`name`, `description`) plus polish fields
   `applies_to`, `kind`, `budget_tokens`, `resources`, validates with zod, and rejects when
   `name` ≠ parent directory name or frontmatter/body is invalid.
3. `compose({ task, domains, role })` builds a deterministic bundle in fixed order:
   `base-engineering-policy` → task protocol → domains sorted lexicographically → role.
   Missing required protocols throw. Bundle `promptText` concatenates SKILL bodies only
   (progressive disclosure: resources are not inlined).
4. Bundle `hash` is a stable SHA-256 over the canonical (sorted-key) JSON of each member's
   `name`, `kind`, `body`, and `resources` list — suitable for forensic logging.
5. `fitToBudget(bundle, maxTokens)` keeps composition order and drops trailing members
   (never the base protocol) until `sum(budget_tokens) ≤ maxTokens`, or throws if even base
   alone exceeds the cap. Does not truncate markdown bodies.
6. `readResource(protocolName, relativePath)` returns file contents only for paths listed in
   that protocol's `resources` and contained under the protocol directory (no `..` escape).
7. Initial protocol set is present and loadable: `base-engineering-policy`; tasks
   `bugfix`, `feature`, `refactor`, `simplify`, `investigate`; domains `typescript`,
   `react-native`; roles `reviewer-correctness`, `reviewer-regression`,
   `reviewer-adversarial`, `reviewer-architecture`, `reviewer-simplicity`, `evidence-agent`,
   `defender`, `scope-guardian`, `planner`, `judge`.

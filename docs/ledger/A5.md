# A5 — Run Engine: phase loop, control plane, crash resume, clean-round invalidation

## Contract

Scope: `src/engine/**`. May import `domain/`, `shared/`, `store/`, `scheduler/` only
(dependency-cruiser enforced). Phase business logic (discovery, baselining, LLM calls, gates)
is stubbed; real drivers land in later blocks.

1. `pnpm check` passes.
2. `RunEngine.createRun` appends `run.created` (phase `CREATED`, control `RUNNING`) and returns the run.
3. `RunEngine.tick` drives every active run once: control housekeeping first, then (when
   `mayDispatchJobs`) the registered phase driver; when the driver completes, appends
   `run.phase_changed` via `transitionPhase`. Terminal phase or terminal control skips work.
4. Control plane: `pause`/`resume`/`stop`/`kill` append `run.control_changed` using
   `applyControlCommand`. After `scheduler.settle(runId)`, `PAUSE_REQUESTED` with no in-flight
   jobs becomes `PAUSED` via internal `quiesced`; `STOP_REQUESTED` with no in-flight becomes
   `STOPPED` via `stopped` and appends `run.terminated` (`stopped_by_user`). `kill` is absorbing
   (`KILLED`, or stays `STOPPED` if already stopped) and appends `run.terminated` (`killed_by_user`)
   when newly killed.
5. Crash resume: `recover()` calls `scheduler.recover()` then continues active runs from their
   projected `phase`/`control` (SQLite events + projections are source of truth; no separate
   engine checkpoint).
6. Clean-round invalidation: `hasConverged` counts only rounds whose `checkpointHash` equals
   `run.currentCheckpointHash`. Changing the hash (via `setCurrentCheckpoint`) makes prior
   rounds for other hashes non-counting without deleting them. `CONVERGENCE_CHECK` stub advances
   to `DONE` only when `hasConverged(..., requiredCleanRounds)`; otherwise stays put (or the
   test drives an alternate edge).
7. Default stub drivers auto-advance along a valid happy-path edge per tick (except
   `CONVERGENCE_CHECK` as above). Custom drivers may be registered per phase.

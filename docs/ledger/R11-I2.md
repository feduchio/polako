**Date:** 2026-09-25.

The manifest is written once, after model discovery has restored the catalog (`createDiscoveringModelsDriverFromCatalog`), and the worker factory writes it if discovery did not. It is not written in `DaemonService.createRun`: the catalog is empty there, so a progress reason recorded at that moment would be a lie by the time a worker started.

`selectProgressModels` uses `isCostEligible` against `routing.costEligibility`. Under `free_only` a paid model is still excluded (the existing progress test). Under `ceiling` a paid strict-schema family counts.

`review.axis_exhausted` is registered. It was already emitted.

The final report lists each mechanism as `on` or `off` with its reason.

## The one mutant both lanes agreed survives

Both lanes reported it independently and both classified it non-blocking, for the same reason: it is
behaviourally identical, and MC1 is a **shape** clause — "the same first line as the siblings at `:86`
and `:107`" — which is verified by reading the source, not by running it. Grok additionally tried

input cannot be killed by any behavioural check, so demanding one would restart B-selfhost-8's

divergence between three functions that agree on policy.

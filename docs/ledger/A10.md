# A10 — RepositoryIntelligence: BasicIntel, CodeGraphCli, CompositeIntel, probes

## Contract

Scope: `src/intel/**` (+ optional `fixtures/intel-sample/**`). May import `domain/`, `shared/`,
`sandbox/` (process runner only). Bound to a concrete workspace path (worktree), never an
implicit “main repo”.

1. `pnpm check` passes.
2. `RepositoryIntelligence` exposes: `prepare()`, `explore(query)`, `symbol(name)`,
   `callers(name)` / `callees(name)`, `impact({ symbol?, files? }, depth)`,
   `affectedTests(files)`, `refresh(changedFiles)`, `health()`.
3. `BasicIntel` works without CodeGraph: search (ripgrep when available, otherwise a Node
   directory walk), symbol-ish matches, heuristic import callers/callees for TS/JS, BFS
   impact, heuristic `*.test.*` / `__tests__` mapping, and `health()` reflecting readiness.
4. `probeCodeGraph(binary?)` reports `{ available, version, fts5, reason? }`. Native backend
   is eligible only when available ∧ fts5; A10 does not ship a native binding — probe is the
   gate for later blocks.
5. `CodeGraphCli` invokes the configured binary with JSON output, runs `prepare`/`init` only
   inside the bound workspace (writes `.codegraph/` there), never copies `.codegraph/` from
   another tree, and surfaces staleness when `refresh` notes changed files without re-index.
   Missing/unhealthy binary → `health().ok === false` (no throw on `health`).
6. `CompositeIntel` prefers a healthy CodeGraphCli (or future native), else BasicIntel;
   degradation is recorded on `health().degradedFrom` / `health().backend`.
7. Fixture + stub-CLI integration test covers explore/symbol/impact paths and the no-copy
   `.codegraph/` rule.

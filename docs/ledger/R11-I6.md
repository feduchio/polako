**Date:** 2026-09-25.

- `agents.test.ts` now requires the words "fresh evidence in this loop", including on a task that does not touch product code. Disabling `hasLoopEvidence` used to stay green because the empty-diff guard said "finish rejected" too.
- `silencingFromSkippedBaselineFailures` is asserted directly: a baseline failure that passes while the skip count rises is `skip_only`. An unchanged skip count is not.

- A completed review round whose model is no longer selectable records `review.canary_recorded` with `verified: false` and `reviewer no longer selectable`, and the run stops at `NEEDS_HUMAN` / `review_unverifiable`.

The two guards in `BudgetTracker.admit` (the latch and the set identity) each block the same stale-release sequence, so a test cannot kill one while the other remains. The existing test "does not let a stale release delete a live hold's accounting" kills removing both. They stay.

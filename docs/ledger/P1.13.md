# P1.13 — `runtime=required` happy path

**Status:** FROZEN, revision 1. **Base:** HOST `e903b9e`.
**Plan reference:** `docs/PLAN.md` §3 P1.13. **Goal:** G2.
**Dependencies:** accepted P1.6 and P1.8. **Process:** v3.

## Mandatory clauses

**MC1 — real required run.** A daemon E2E on `fixtures/resume-dup-fetch`
creates the run through `DaemonService.handle("run", { runtime: "required" })`
with the configured `ScriptedProvider` and reaches `DONE`. No runtime mode or
evidence is patched into the run.

**MC2 — executable runtime identity.** The fixture provides a safe in-tree
`runtime/check.mjs` that exercises the fixed retry behavior. After integration
the executed `RuntimeEvidence` is stored in a corpus entry for the accepted
checkpoint. Its script bytes are also stored as an `AcceptanceArtifact` of
kind `runtime_scenario`; the entry's executable descriptor carries that
artifact id, `runtime/check.mjs`, and its exact hash.

**MC3 — restart stability.** Close the daemon at `CONVERGENCE_CHECK`, construct
a fresh service over the same home, and re-read the same corpus entry id,
runtime evidence id, artifact id, relative path and hash.

**MC4 — evidence is binding.** Before the final convergence tick, delete only
the runtime corpus projection row. The same run must not reach `DONE`.
Rebuilding projections from its immutable events restores the row; after one
additional normal clean review round the same run reaches `DONE`. A unit-only
call to `runtimeAllowsDone` is insufficient.

**MC5 — no P1.12 or P2 scope.** Reuse the accepted daemon E2E harness and
cleanup/causality checks. Do not change runtime policy, convergence thresholds,
or replay-set accounting.

## Acceptance criteria

1. The required run records passed evidence for its integrated checkpoint and
   reaches `DONE`.
2. Removing the evidence projection prevents `DONE` for that same run.
3. Entry/evidence/artifact ids, path and hash survive daemon restart exactly.
4. The runtime script fails on the fixture's baseline and passes on the
   integrated fix, so it is behavioral evidence rather than `process.exit(0)`.
